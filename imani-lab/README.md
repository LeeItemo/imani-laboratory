# Imani Laboratory Hospital Network

A modern hospital and laboratory website built for a multi-branch network that needs to communicate across locations.

## Features

- Centralized hospital overview and branch status
- Shared communication and referral updates
- Branch-level service highlights and operational alerts
- Responsive layout for desktop and mobile screens

## Run locally

```bash
npm install
npm run dev -- --host 0.0.0.0
```

Then open the local Vite URL shown in the terminal.

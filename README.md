# Imani Laboratory Hospital Network

This workspace contains a responsive hospital website concept for a multi-branch laboratory and healthcare network.

## Site features

- Centralized hospital overview
- Multi-branch status cards
- Shared communication and referral updates
- Service and network health panels
- Responsive layout for desktop and mobile devices

## Open locally

Open the generated homepage in a browser using the workspace file:

- index.html

This is a static front-end prototype, so no install step is required.
